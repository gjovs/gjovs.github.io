## 关于我

我构建后端系统，把复杂的运营流程变成可靠的软件。目前我在 **Shopee** 担任后端工程师，负责设计数据和机器学习产品背后的服务、异步工作流与系统集成，以及配套的运营工具。

我的主要技术栈仍是 Node.js/TypeScript，同时也具备高水平的 Python 实践经验，使用 FastAPI 构建后端和模型推理服务。我还使用 Fastify、PostgreSQL、Redis 和异步任务处理。根据产品需要，我也会使用 Next.js/React 开发前端。我在 AI 方面的工作立足于后端工程：微调 SigLIP2 等多模态模型，通过基于 GPU 的 FastAPI 服务提供 BGE-M3 嵌入以及情感分析和图像匹配模型，并构建配套的队列、缓存、持久化和可观测性。

加入 Shopee 之前，我曾在 PCI-DSS 合规环境中构建支付集成和便于审计的微服务。这段经历至今仍影响着我看待可靠性、数据完整性，以及那些维持生产环境稳定运行的“无聊”细节的方式。
